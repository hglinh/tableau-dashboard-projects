# Tableau Dashboard Projects

## Overview

This repository contains Tableau dashboard and business intelligence projects focused on data visualization, KPI analysis and business insights.

The projects demonstrate dashboard design, interactive visualization and analytical thinking using Tableau and Excel datasets.

# Included Projects

## 1. HR Analytics Dashboard

Features:
- Employee attrition analysis
- Department-wise attrition
- Age group analysis
- Job satisfaction analysis
- Gender-based attrition insights

### Key Insights
- R&D has the highest attrition rate
- Employees aged 28–36 form the core workforce
- Male employees under 35 have higher attrition risk

# 2. Music Analytics Dashboard
Features:
- Genre analysis
- Danceability analysis
- Valence analysis
- Energy vs Danceability scatter plot
- Filter Action
- Highlight Action
- URL Action
### Key Insights
- Pop is the most popular genre
- K-Pop has the highest valence
- Disco has the highest danceability
